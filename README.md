# Skillwright

An iPhone / iPad app for writing, checking and publishing AI-agent instruction files — `SKILL.md`, `CLAUDE.md`, `AGENTS.md` — straight to GitHub.

iPhone と iPad で、AI エージェント向けの指示ファイル（`SKILL.md`・`CLAUDE.md`・`AGENTS.md`）を書いて、決まりどおりか検査して、GitHub に反映するアプリです。

## Status / 状況

Design phase. The app is not built yet.
デザインの段階です。アプリはまだできていません。

## Design / デザイン

- [design/design-spec.md](design/design-spec.md) — detailed design (Japanese) / 詳細設計書
- [design/mocks/](design/mocks/) — screen mockups, light and dark (SVG + PNG) / 画面のモック
- [design/review/](design/review/) — contact sheets / 一覧画像
